# Вычислительная математика

[English](README.md) | **Русский**

Лабораторные работы на Python, посвящённые численным методам, их точности
и сходимости. Каждая работа включает выполненный Jupyter Notebook с формулами,
результатами, графиками и выводами, а также реализацию на Python.

README доступны на английском и русском языках. **Отчёты в notebook’ах, подписи
на графиках и комментарии в коде — на русском.** Сохранённые результаты
в notebook’ах можно просматривать на GitHub.

## Лабораторные работы

| Лабораторная | Тема | Содержание |

| 1 | [Численное дифференцирование](numerical_differentiation/README.ru.md) | Пять разностных формул; зависимость абсолютной погрешности от шага для пяти функций на графиках с логарифмическими осями. |
| 2 | [Численное решение систем линейных уравнений](numerical_solution_of_linear_systems/README.ru.md) | Девять прямых и итерационных методов; сходимость по невязке, проверки применимости и влияние параметра SOR. |

## Запуск notebook’ов

Используйте Python и расширения Python и Jupyter для VS Code. Установите
зависимости из файла `requirements.txt` соответствующей лабораторной,
откройте её файл `.ipynb`, выберите ядро Python и нажмите **Run All**.

В README каждой лабораторной приведены команды установки, настраиваемые параметры,
а также сведения о результатах и проверках.
