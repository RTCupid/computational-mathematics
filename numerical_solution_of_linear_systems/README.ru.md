## Что реализовано

В [solvers.py](solvers.py) самостоятельно реализованы все девять методов:

1. Гаусс с выбором максимального по модулю элемента в текущем столбце.
2. LU-разложение без перестановок (Дулиттл) и две треугольные подстановки.
3. Якоби.
4. Зейдель.
5. Последовательная верхняя релаксация (SOR).
6. Градиентный спуск с точным выбором шага — наискорейший спуск.
7. Одномерный метод минимальных невязок.
8. Сопряжённые градиенты (CG).
9. Стабилизированные бисопряжённые градиенты (BiCGStab).

`numpy.linalg.solve` используется только для эталонного сравнения и вычисления
диагностических матриц итераций. Все методы решают исходную систему;
перехода к нормальным уравнениям и предобусловливания нет.

Для итераций одинаковы `x0 = 0`, `rtol = 1e-10`, `atol = 1e-12`, `max_iter = 10000`.
Критерий: `||b − A @ x||₂ <= atol + rtol * ||b||₂`.
В истории сохраняется истинная невязка, пересчитанная по текущему решению,
включая начальное приближение. Вектор невязки внутри CG/BiCGStab может вычисляться
рекуррентно, но не используется вместо истинной невязки для остановки и графиков.

## Как задать другую СЛАУ

В разделе 2 notebook замените `A, b = variant_m()` своими массивами
`np.array(..., dtype=np.float64)` или загрузкой из CSV через `np.loadtxt`.
Там же задаются начальное приближение, допуски, предел итераций и `OMEGA`.
После изменений выполните notebook целиком.

Код работает с вещественными квадратными системами произвольной небольшой
размерности; используются плотные матрицы. SPD проверяется для CG и спуска;
для стационарных методов проверяется диагональ. В отчёте вычисляются
спектральные радиусы матриц Якоби, Зейделя и SOR. Если метод неприменим,
произошёл обрыв, расходимость либо исчерпан лимит, результат получает
соответствующий статус, а последнее приближение не выдаётся за сошедшееся решение.
Близость к нулю проверяется с учётом масштаба матрицы или скалярного произведения.

Теоретическое обоснование варианта м) в тексте отчёта относится к исходной матрице;
при её замене интерпретируйте результаты по новой диагностике.

## Результат для варианта м)

При параметрах по умолчанию все методы успешно решают систему.
Число обусловленности `κ₂(A) ≈ 1.48155`.
Невязки Гаусса и LU — около `4.5e-15`.

| Итерационный метод | Итерации |
|---|---:|
| Якоби | 15 |
| Зейдель | 10 |
| SOR, ω = 1.05 | 12 |
| Наискорейший спуск | 13 |
| Минимальные невязки | 12 |
| CG | 10 |
| BiCGStab | 6 |

Число итераций не равно времени работы: у BiCGStab до двух основных
матрично-векторных произведений за итерацию, плюс проверка истинной невязки.
SOR с выбранным параметром здесь медленнее Зейделя; отдельный эксперимент
показывает влияние ω. Значения на уровне машинной точности могут зависеть от платформы.

Рисунки сохранены и в notebook, и в [figures](figures):

- `convergence_all.png` — семь методов на одном графике;
- `convergence_individual.png` — отдельная панель для каждого метода;
- `sor_parameter.png` — влияние параметра релаксации.

Во всех рисунках норма невязки имеет логарифмическую шкалу,
номер итерации — линейную. Нулевые невязки пропускаются только при отображении.

приближение, формулы первого шага, статусы остановки и некорректный ввод.
