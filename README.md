# Computational Mathematics

**English** | [Русский](README.ru.md)

Python laboratory assignments exploring numerical methods, their accuracy,
and convergence. Each lab includes an executed Jupyter notebook with formulas,
results, plots, and conclusions, alongside the Python implementation.

The READMEs are available in English and Russian. **Notebook reports, plot labels,
and code comments are in Russian.** Saved notebook outputs can be viewed on GitHub.

## Laboratory assignments

| Lab | Topic | Contents |
|---|---|---|
| 1 | [Numerical differentiation](numerical_differentiation/README.md) | Five finite-difference formulas; absolute error versus step size for five functions, plotted on log–log axes. |
| 2 | [Numerical solution of linear systems](numerical_solution_of_linear_systems/README.md) | Nine direct and iterative methods; residual convergence, applicability checks, and the effect of the SOR parameter. |

## Running the notebooks

Use Python with the Python and Jupyter extensions for VS Code. Install the
dependencies listed in the lab's `requirements.txt`, open its `.ipynb` file,
select the Python kernel, and choose **Run All**.

Each lab's README provides installation commands, configurable parameters,
and details about its results and checks.
